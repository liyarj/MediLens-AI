# MediLens AI — CT Model

CT imaging analysis module for the MediLens multimodal medical screening prototype.

## Components

- ResNet18-based CT model
- CT preprocessing pipeline
- CT prediction API/model inference code

## Files

- `models/predict_ct.py` — CT inference
- `models/train_ct.py` — CT model training
- `preprocessing/preprocess.py` — CT preprocessing
- `models/ct_resnet18.pth` — trained model weights

## Dataset

The CT dataset is kept outside the GitHub repository.

## Disclaimer

This project is a hackathon prototype and is not intended for clinical diagnosis.
